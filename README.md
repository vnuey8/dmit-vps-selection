# 海外VPS购买：从线路、机房到套餐价格，一次把选购逻辑理清

海外VPS购买真正麻烦的地方，通常不是“哪家有 VPS”，而是**你到底该为线路、机房、流量还是硬件付钱**。

同样是 2 vCore、4GB 内存，有的方案月付不到 20 美元，有的要接近 130 美元；同样放在亚洲，香港、东京和洛杉矶的网络用途又完全不同。只盯着 CPU、内存和 SSD，很容易买到“参数看着很香，实际用途不对”的机器。

这篇就按实际购买决策来拆：先判断你需要什么线路，再看机房和配置，最后核对当前价格、退款规则和真实评价。DMIT 会作为其中一个具体案例，因为它目前同时提供洛杉矶、香港、东京节点，并把网络划分为 Premium、Eyeball 和 Tier 1 三类。官网当前页面还显示 AMD EPYC、NVMe、快照、自动备份、SSH Key 等基础能力。

> **先记住一个最重要的结论：海外VPS购买时，面向中国大陆用户的业务，线路往往比“多 1 个 vCore”更值得优先比较。**
> DMIT 自己对 Premium、Eyeball、Tier 1 的定位也很明确：Premium 针对中国大陆及亚太优化；Eyeball 采用较经济的中国住宅网络路由；Tier 1 则主要面向不需要中国专用优化、但需要全球或亚太连接的业务。

## 海外VPS购买，第一步不是看价格，而是确定访问者在哪里

先把需求分成三类，选起来会简单很多。

### 面向中国大陆用户

这种场景包括中文网站、跨境电商落地页、API、中后台、远程管理节点等。

DMIT 当前把 Premium Network 定位在中国大陆和亚太方向，包含中国电信 CN2 GIA，并说明其网络还与中国电信 AS4809、中国联通 AS9929、中国移动国际 AS58807 做直接互联。官网同时强调，香港到深圳的参考延迟约为 15ms，东京到上海的参考延迟约为 30ms；这些都是参考值，实际情况仍取决于接入网络、线路和时段。

因此，做中国大陆访问型业务时，比较 VPS 不应该只看“10Gbps”这种醒目的数字。**线路类型、目标用户所在地区、三网实际路由**通常更值得先看。

### 面向亚洲其他地区

如果主要用户在日本、韩国、香港、新加坡等地，东京通常会比洛杉矶更容易形成较短的网络路径；如果用户主要分布在美国，则洛杉矶自然更有位置优势。

DMIT 的东京节点官方定位就是东亚节点，强调中国及亚洲内部路由；洛杉矶则被定位为北美旗舰节点，具备更高的全球网络容量。

### 面向欧美或全球用户

这类业务不一定需要为中国优化线路额外付费。DMIT 的 Tier 1 Network 就是针对这一需求：重点在亚太、北美等方向的常规全球连接，而不是中国大陆专用优化。官网还把备份、监控、CI/CD、DevOps 和一般计算列为适合场景。

换句话说，**不要因为“CN2 GIA”四个字听起来高级，就给一个根本不服务中国用户的项目增加网络成本。**

## DMIT 的线路怎么选：Premium、Eyeball、Tier 1 有什么区别？

DMIT 当前的产品结构很容易让第一次购买 VPS 的人迷糊，因为同一个机房里可能同时存在多个网络系列。

| 网络系列 | 官方定位 | 更适合的场景 | 需要注意什么 |
| --- | --- | --- | --- |
| Premium | 中国大陆及亚太优化，包含 CN2 GIA | 中国大陆访问、跨境业务、低延迟应用 | 通常承担线路溢价 |
| Eyeball | Tier 1 + CMI/CMIN2 等中国住宅网络方向 | 中国与全球混合用户、API、博客、开发环境 | 不具备 Premium 同等级别的路由保证 |

DMIT 对三类网络的官方描述就是这个逻辑：Premium 更偏中国大陆与亚太体验，Eyeball 是成本与中国覆盖之间的折中，Tier 1 则不强调中国专用线路。

这里还有一个容易被忽略的细节：**香港 Eyeball 当前仍标注为 Beta**。官网说明该网络还在调整和优化，线路及表现可能变化，因此不建议把它默认当成高稳定生产业务的最终答案。

## 硬件怎么选：AS3、AN4、AN5 不只是名字不同

DMIT 当前公开介绍了三代硬件平台：

* **AN5**：AMD EPYC 9005，Zen 5，DDR5，PCIe 5.0 NVMe。
* **AN4**：AMD EPYC 9004，Zen 4。
* **AS3**：AMD EPYC 7003，Zen 3。

官网对 AN5 的定位偏高性能，强调单核、多核和 NVMe Gen5；AN4 偏成熟的通用计算；AS3 则强调较低的每核心成本，适合预算有限、测试和入门部署。

所以“AN5 一定比 AS3 更适合我”也不是完整的购买逻辑。假如你的任务只是跑监控、备用节点、低流量 API 或 CI/CD Runner，一个便宜的 Tier 1 方案可能已经够用。反过来，如果应用对计算性能和 I/O 更敏感，再考虑更新的硬件平台就合理得多。

## VPS 购买前，最值得查的不是跑分，而是这些限制

### 流量怎么算？

DMIT 当前不同网络系列使用的流量表达方式并不完全一样。

普通 Premium / Eyeball 产品通常直接给出月度流量，例如 1000GB、2000GB 或 10000GB；Tier 1 产品则经常标注 `Max (IN, OUT)`。这意味着不要简单地把所有套餐的“1000GB”理解成完全相同的计费逻辑。

### Tier 1 的 IP 有额外限制

DMIT 当前 Pricing 页面明确提醒：**Tier 1 产品分配的 IP 地址不保证在所有国家或地区都可用**。这件事对于需要特定地区访问、广告账户、业务平台或地区敏感型应用的用户尤其值得提前确认。

另外，DMIT 的条款还说明 IP 地址是随机分配的，不能指定特定 IP 段或某个具体 IP；IP 的地理归属也不是绝对保证。

### SLA 不要看得太宽松

当前服务条款写明，DMIT 目前能够提供的是 99% SLA；如果适用 SLA 低于对应门槛，可以按条款获得一定额度的补偿。这里要注意，**SLA 补偿机制不等于你的 VPS 一定不会发生网络问题**。

## 退款规则，这一项一定要看

这一点在海外VPS购买里非常重要，因为很多人买 VPS 时会先被“月付”两个字放松警惕，直到真正遇到线路、IP 或兼容性问题才发现退款规则并不是“随时退”。

DMIT 当前帮助文档显示：

**新订单购买不超过 3 天、实例流量使用不超过 30GB时，可申请全额退款；新订单不超过 30 天，则符合规则时可以申请按剩余价值计算的部分退款。**退款还会受到同系列退款次数、付款方式和其他条款限制。

退款还有两个很实际的细节。

第一，退款到原支付方式可能扣除支付服务商费用；退回 DMIT 账户余额则没有这一项费用。

第二，申请退款后实例可能会被停止，而且确认退款后实例数据会删除且不可恢复，所以在点退款之前先备份。

如果你买的是 VPS 用来做正式业务，这几条远比“SSD 是 80GB 还是 100GB”更值得在下单前读一遍。

## 付款和续费也别忽略

DMIT 的帮助文档显示，PayPal 或信用卡付款需要完整的个人及地址信息；如果 PayPal 未验证、信用卡不支持 3D Secure，或者 Stripe 风控拦截，也可能导致付款失败。

月付实例的续费账单通常会在到期前 7 天生成；实例到期后，系统通常保留实例 3 天，期间补缴可以恢复，超过这个时间实例会被自动删除，数据不可恢复。

所以做正式站点时，**不要把“自动续费”理解成绝对保险**。最好还是给重要业务设置自己的到期提醒和备份机制。
